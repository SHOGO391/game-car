# 円環型じゃんけん鬼ごっこ

じゃんけんの勝者が16マスの円環上を移動するブラウザーゲームです。1台での対戦、CPU対戦、Socket.IOによる2人対戦に対応しています。

## 起動

Node.js 24以降を使用します。

```sh
npm ci --ignore-scripts
npm start
```

`http://127.0.0.1:3001` を開いてください。オンライン対戦は1人がルームを作り、もう1人が4桁のコードで参加します。

初期設定はこの端末からのみ接続できます。LANから利用する場合は `HOST=0.0.0.0 npm start` とし、必要な相手にだけポートを開いてください。別のオリジンにフロントエンドを置く場合は、`ALLOWED_ORIGINS=https://game.example.com` のように許可するオリジンをカンマ区切りで指定します。公開サーバーではHTTPSとリバースプロキシ側の接続制限を設定してください。`PORT` でポートを変更できます。

## 検証・通信の制約

```sh
npm test
npm audit --audit-level=low
```

通信データの型・範囲とイベント順序を検証し、1接続1ルーム、最大100ルーム・200接続、10秒あたり100イベント、1時間の無通信タイムアウトを設定しています。静的配信は画面と `css/`、`js/` に限定しています。

ルームコードは認証機能ではありません。現在の対戦はクライアントによる位置・勝敗の申告を含み、改変クライアントによる不正勝利を完全に防ぐ設計ではありません。信頼できる相手とのカジュアルな対戦用です。
